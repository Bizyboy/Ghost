## Video Production Guide

### Script Structure (10 min video)
```
00:00-00:30 - Hook (grab attention)
00:30-01:00 - Intro (set expectations)
01:00-08:00 - Main content (value)
08:00-09:30 - Recap key points
09:30-10:00 - Call-to-action (subscribe)
```

### Thumbnail Formula
- Bold text (3-5 words max)
- High contrast colors
- Emotional expression/reaction
- Curiosity gap
- Clear and readable

### Title Formula
- Include main keyword
- Create curiosity
- Use numbers when possible
- Keep under 60 characters
- Test emotional triggers

## SEO Optimization

### Title
- Front-load keywords
- Include year (2024)
- Use power words
- Create intrigue

### Description
- First 150 chars most important
- Include 3-5 keywords naturally
- Add timestamps
- Include affiliate links
- Call to action

### Tags
- 15-20 relevant tags
- Mix broad and specific
- Include misspellings
- Use TubeBuddy suggestions
