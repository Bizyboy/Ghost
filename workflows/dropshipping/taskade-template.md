# Dropshipping Automation - Taskade Template

## Daily Tasks

### Product Research (9:00 AM)
- [ ] Run ChatGPT product research query
- [ ] Analyze trending products in target niches
- [ ] Check competition on Amazon/Shopify
- [ ] Select 5-10 products to test
- [ ] Document findings in Notion

### Supplier Management (10:00 AM)
- [ ] Search Alibaba for selected products
- [ ] Compare supplier prices and ratings
- [ ] Contact suppliers for samples
- [ ] Negotiate bulk pricing
- [ ] Update supplier database

### Product Listings (2:00 PM)
- [ ] Generate product titles with ChatGPT
- [ ] Write SEO-optimized descriptions
- [ ] Create product images in Canva
- [ ] Set pricing with 40% markup
- [ ] Publish to Shopify store

### Marketing (4:00 PM)
- [ ] Create Facebook ad campaigns
- [ ] Design Instagram stories
- [ ] Write email marketing copy
- [ ] Schedule social media posts
- [ ] Track ad performance

### Order Processing (Ongoing)
- [ ] Monitor new Shopify orders
- [ ] Process orders with suppliers
- [ ] Update tracking information
- [ ] Send customer confirmations
- [ ] Handle customer inquiries
